# About DGTL Sunrise

DGTL Sunrise is an AI-first marketing engineer agency. Sunrise Consulting LLC ships dgtl-connector, a Grok Bot plugin that connects agents to marketing accounts you already administer.

The free path covers Google Analytics 4, Search Console, and Tag Manager on your machine (read and manage). Report bytes do not go through DGTL. Pro adds a hosted gateway for Google Ads, Meta, and TikTok, plus Pro-gated Merchant Center on your machine, with confirmation before live edits. The public docs live on this site: install command, platform capabilities, guardrails, and product pages.

We are not a managed-agency replacement. The plugin pulls, analyzes, and recommends. A human still publishes. Agents must not invent metrics the APIs did not return, and must never ask you to paste secrets into chat.

Based in Coeur d’Alene, Idaho. Contact: contact@dgtlsunrise.com · support@dgtlsunrise.com.
