DGTL Sunrise. /connector

dgtl-connector

A Grok plugin. One offering — not the company.

What it is

Read-only GA4, Search Console, and Tag Manager on the machine where you installed it. Auth and report bytes stay there.

What it is not

Not a dashboard. Not a write-back tool. Not a hosted analytics suite.

Free

GA4, Google Search Console, and Google Tag Manager. Local only.

Pro · $19/mo flat

Google Ads and Meta through the hosted gateway. Start at /connector or https://www.dgtlsunrise.com/connector.

Install

grok plugin install dgtlsunrise/dgtl-connector

Then paste the prompt below to your agent.

Paste this to your agent

You have dgtl-connector on this machine.

Use it for read-only GA4, Search Console, and Tag Manager. Auth and report bytes stay on this computer — never paste tokens, refresh tokens, or license JWTs into chat or email.

When I ask for numbers:
1. Run google_whoami and say which Google account is connected.
2. If more than one property/site/container is visible, list them and ask which one. Never pick the first silently.
3. Cite the resource ID on every number. Empty rows are not an auth failure.
4. Ads/Meta tools need DGTL Pro ($19/mo flat) plus the hosted gateway. If you get LICENSE_REQUIRED, say so and point at https://www.dgtlsunrise.com/connector — do not invent Ads or Meta rows.

If something looks like a plugin bug after you diagnose it, offer feedback_prepare to support@dgtlsunrise.com with my reply email, show the draft, and only feedback_send after I approve.
