Privacy Policy

Effective September 6, 2026 · Sunrise Consulting LLC, doing business as DGTL Sunrise · 2152 W Lima Pl, Coeur d'Alene, ID 83814 · contact@dgtlsunrise.com · 858.354.3666

This policy covers dgtlsunrise.com, the Grok Bot plugin, and related consulting work. It is written for people and for Google's OAuth verification of the plugin.

What the plugin is

The Grok Bot plugin runs locally on the user's Grok Bot computer. You connect Google accounts you already own so Grok can read marketing data and answer questions in that session. v1 is read-only. The plugin does not create, update, or delete campaigns, tags, properties, or listings.

Google user data we access

When you complete Google OAuth, the plugin requests access only to the APIs you enable:

  • Google Analytics (GA4) : read property, report, and configuration data you can already see in Analytics.
  • Google Search Console : read site and query performance for properties you verify.
  • Google Tag Manager : read container and tag configuration. No publishes in v1.
  • Google Business Profile : optional and feature-flagged. Read listing information you already administer, only if that flag is on.
  • Google Ads : not in the free plugin. Planned as a paid DGTL subscription, read only, through the gateway described below. Product page: /google-ads.

We request the minimum read scopes needed for those features. We do not request Gmail, Drive, Calendar, or Contacts.

Limited Use. DGTL Sunrise's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide and improve the user-facing features of the Grok Bot plugin. We do not sell it. We do not use it for advertising. We do not transfer it to third parties except as needed to run a request you initiated or as required by law.

Where that data lives

Free plugin (GA4, Search Console, GTM, and flagged GBP). OAuth tokens stay on your computer. Report bytes are fetched into the local Grok session so the model can answer you. Sunrise Consulting LLC does not receive those report bytes and does not store them on DGTL servers.

Paid Google Ads and Meta Ads reads (future DGTL subscription). Those calls will go through an allowlisted DGTL gateway. The gateway attaches the credentials needed to complete the request and returns the vendor response to your session. The gateway does not store the report bytes. Meta is not a Google API; it is listed here because the same product will use it later under a paid plan.

If we ever need to keep a credential so a paid connector can keep working, we will say so in this policy before that ships, and it will still be used only to serve your request.

How we protect Google user data

This section states how Google user data is protected on the free plugin path and, when it ships, on the paid gateway path.

  • Least privilege. The free plugin requests only read-only scopes for the Google products you connect. We do not request Gmail, Drive, Calendar, or Contacts.
  • Local token custody (free path). OAuth tokens stay on your Grok Bot computer. Sunrise Consulting LLC does not receive those tokens and does not store them on DGTL servers.
  • Transit. Google API calls and this marketing site use HTTPS/TLS.
  • Access control. Only the signed-in Grok Bot session on that machine can use the tokens. There is no shared multi-tenant DGTL store for free-plugin Google tokens.
  • No DGTL persistence of free-path report bytes. Report bytes stay in the local session. They are not stored on DGTL servers.
  • Paid gateway (when shipped). Paid Ads/Meta reads will go through an allowlisted DGTL gateway that does not archive report bytes. If we ever store a credential so a paid connector can keep working, we will disclose that here before it ships.
  • Revocation. Revoke access at Google Account permissions, delete the local plugin data on your machine, and email contact@dgtlsunrise.com if you need us to check what, if anything, we hold from a consulting engagement or paid subscription.
  • Limited Use. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, as stated above.

What we collect on the website

The marketing site is static. If you email or call us, we keep that correspondence to reply and, if you hire us, to do the work. We do not run a public account system on this domain. Server logs from our host (Cloudflare) may include IP address, user agent, and the URL requested, for security and uptime.

Consulting engagements

If you hire Sunrise Consulting LLC, we process whatever you send us to do the job: briefs, access you grant, drafts, invoices. That material is held under the engagement, not mixed into the plugin's Google data. We do not use client consulting files to train public models.

Sharing

We do not sell personal information. We share data only with processors who host this site or, for paid Ads/Meta, the allowlisted gateway that completes your request; with Google or Meta when you authorize an API call; or if the law requires it.

Retention and your choices

Local plugin data lasts as long as you keep the local session and tokens. Revoke access any time at Google Account permissions. Delete the local Grok / plugin data on your machine the same way you delete other local app data. Email contact@dgtlsunrise.com to ask what, if anything, we hold from a consulting engagement or a paid subscription, and we will delete it unless we are required to keep it.

Children

The plugin and this site are for business users. We do not knowingly collect data from children under 13.

Changes

If this policy changes in a material way, we will update this page and the effective date. The current version lives at https://www.dgtlsunrise.com/privacy.
