The tool

Reads performance. Confirm-gated pause/enable is live.

Sunrise Consulting LLC, doing business as DGTL Sunrise, builds dgtl-connector: a Grok Bot plugin plus a hosted gateway. This page is the Google Ads API product page for that gateway.

The agent can read account and campaign performance for Search, Display, Performance Max, Shopping, Video, and Demand Gen. Management tools exist behind a production flag: pause or enable existing campaigns after the user confirms, then budget later. Google Ads API Basic Access already includes campaign management. Production gateway flag is on. Every write still needs your confirm with the customer id.

It does not create campaigns, ads, or keywords. It does not use App Conversion Tracking or the Remarketing API. Not autopilot.

Intended audience: marketing operators, internal and external, who already administer the Google Ads accounts they connect.

How the API is called

Consent C OAuth. Worker plus MCC token.

Customers connect their own Google Ads accounts with OAuth. That client is Consent C, on Google Cloud project 960111255083. It is a separate OAuth client from the free plugin.

Consent C

Customer OAuth

The user signs in with a Google account that already administers the Ads customer. Tokens are not pasted into chat. Scope is Ads reporting, not Gmail, Drive, Calendar, or Contacts.

Gateway

Cloudflare Worker

An allowlisted Worker proxies Google Ads API calls. It attaches the Sunrise Consulting LLC MCC developer token on allowlisted calls (reporting today; mutate later when flagged on) and returns the vendor response. It does not archive report bytes.

Two OAuth clients

Free GA4 is separate

Free local GA4, Search Console, and Tag Manager use a different OAuth client. Auth and report bytes stay on the machine where the plugin is installed. That path is not part of this Google Ads developer token request.

Pro Google Ads reads go through the hosted Worker and the MCC token. Meta is not a Google API. It is listed on /connector because the same paid plan may use it later.
