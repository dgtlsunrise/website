Sunrise Consulting LLC, doing business as DGTL Sunrise, builds dgtl-connector: a Grok Bot plugin plus a hosted gateway. This page is the Google Ads API product page for that gateway.

Pro customers connect their own Google Ads login. That path is separate from free Google Analytics, Search Console, and Tag Manager. The developer token stays on the Worker, never on the user's machine. The agent reads performance through closed recipes (no raw GAQL from the client).

With your confirm in that chat turn (digits-only customer id in the confirm phrase), the agent can pause or enable campaigns, ad groups, keywords, and ads; update daily budget within product spend caps; and create with dry-run propose-first. Creates default PAUSED so spend does not start without a separate enable. The Worker builds closed mutate ops only — clients cannot supply raw mutateOperations.

Create surface (all confirm-gated, PAUSED defaults): Search campaign bundles and RSA; Search keywords; Display plus Responsive Display Ads; IMAGE asset upload; Performance Max with uploaded or existing assets; Shopping when merchant_center_id is known, plus listing groups; Video, Demand Gen, App, and Hotel named campaign creates. Local create is not offered (Google sunset — use PMax). Smart create is not advertised. No App Conversion Tracking or Remarketing API. No autopilot.

Intended audience: marketing operators who already administer the Google Ads accounts they connect.

Capability: reporting, confirm-gated manage, and confirm-gated create. Example asks include account spend for the last 7 days, campaign clicks and impressions, and pause, budget, or create after your confirm (PAUSED defaults).

Cloudflare Worker

An allowlisted Worker proxies Google Ads API calls. It attaches the Sunrise Consulting LLC MCC developer token on allowlisted read and confirm-gated mutate calls and returns the vendor response. Mutate is on for Ads. The token never leaves the Worker. It does not archive report bytes.

Free Analytics is separate

Free local Google Analytics, Search Console, and Tag Manager run on the machine where the plugin is installed. Auth and report bytes stay there. That path is not part of this Google Ads developer token request.
