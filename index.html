DGTL Sunrise
Install

dgtl-connector for Grok Bot

A Grok Bot plugin that connects your agent to your marketing accounts. Install it, connect Google (and Meta, Shopify, or TikTok when you need them), then ask in chat.

Free Google Analytics, Search Console, and Tag Manager reads run on your machine. Those report bytes do not go through DGTL.

Install

In Grok Bot, run:

grok plugin install dgtlsunrise/dgtl-connector

Connect the account that owns the property when the plugin asks. Also works in Grok Build and Cursor.

How to use it

  1. Install the plugin in Grok Bot.
  2. Connect the account that owns the property.
  3. Ask in chat.
  4. Approve any confirmation before a live edit or publish.

Never paste access tokens, refresh tokens, or license keys into chat.

Google Analytics 4

Overview

Ask your agent for GA4 properties and reports.

Read

List accounts and properties. Open property details, data streams, and key events. Run reports for the date ranges and metrics you ask for.

Edit

Not in this version. Property setup and admin changes are not available through the plugin yet.

Requirements

Free. Connect Google.

Example asks

  • List my GA4 properties.
  • Sessions and conversions for this property over the last 28 days.
  • Which data streams are on this property?

Guardrails

If you have more than one property, the agent asks which one to use instead of guessing. It cites the property ID on numbers so you can see where a figure came from. It does not invent metrics the API did not return.

Google Search Console

Overview

Ask your agent about verified sites, queries, and URL indexing status.

Read

List sites. Query search performance. Inspect a URL. List and open sitemaps.

Edit

Not in this version. Submitting or changing sitemaps through the plugin is not available yet.

Requirements

Free. Connect Google. The site must already appear in Search Console for that account.

Example asks

  • Which Search Console sites can I access?
  • Top queries for example.com over the last 28 days.
  • Inspect https://example.com/page for indexing issues.

Guardrails

The agent asks which site to use when several are available. Search Console figures stay labeled as Search Console (they are not the same as GA4 sessions).

Google Tag Manager

Overview

Ask your agent to inspect containers. When writes are enabled on your install, it can create or update tags, triggers, and variables, and publish after you approve.

Read

List accounts, containers, workspaces, tags, triggers, and variables. Open a container. Show the live container version.

Edit

Create and update tags, triggers, and variables. Publish a container. Live changes need your confirmation. Writes are off by default until you enable them on the install.

Requirements

Read: free, connect Google. Edit and publish: writes enabled on your install, plus confirmation.

Example asks

  • List my GTM containers.
  • What tags are in GTM-XXXX?
  • Propose a new tag, then publish only after I approve.

Guardrails

Draft or dry-run work stays separate from the live container until you approve publish. The agent will not publish without that confirmation.

Google Ads

Overview

With Pro, ask your agent for account reporting and confirm-gated changes (pause or enable, budgets, keywords, ads, and new campaigns where enabled).

Read

List accessible accounts. Account and campaign reporting. Search performance style queries. Merchant Center link status.

Edit

Pause or enable campaigns, ad groups, keywords, and ads. Update budgets. Add keywords and negatives. Create responsive search and display ads. Create Search, Display, Performance Max, Shopping, Video, Demand Gen, App, Hotel, and Local campaigns. Upload assets. Set geo, language, demographics, schedules, and bidding. Create conversion actions and experiments. Link or unlink Merchant Center. Every live change needs confirmation.

Requirements

Pro ($19 / month). Connect Google Ads under your own login. Details: /google-ads.

Example asks

  • List my Google Ads accounts.
  • Campaign performance for the last 14 days.
  • Pause this campaign after I confirm.
  • Create a paused Search campaign with these keywords.

Guardrails

Creates and status changes wait for your confirmation. Prefer paused drafts when you are testing. Without Pro, Ads tools do not invent results.

Meta Ads

Overview

With Pro, ask your agent for ad account insights and, when Meta access allows, create or update campaigns, ad sets, ads, and audiences.

Read

List ad accounts, campaigns, ad sets, and ads. Pull insights and creative details.

Edit

Create and update campaigns, ad sets, and ads. Upload image or video. Create creatives. Update targeting. Create custom and lookalike audiences and attach them. Live changes need confirmation.

Requirements

Pro. Meta must grant the needed app access for your account. Some write actions stay blocked until Meta finishes that review.

Example asks

  • List my Meta ad accounts.
  • Insights for this campaign over the last 7 days.
  • Create a paused campaign after I confirm.

Guardrails

The agent confirms before live changes. If Meta denies access, it reports that instead of inventing insights or edits.

Shopify

Overview

Read

Edit

Adjust inventory. Live changes need confirmation. That write path is off until you enable it on the install.

Requirements

Connect Shopify on the install.

Example asks

  • What is my shop name and domain?
  • List products.
  • Adjust inventory for this variant after I confirm.

Guardrails

Inventory changes wait for your confirmation. The agent does not invent order or stock numbers.

TikTok Ads

Read

List advertisers and campaigns. Insights.

Edit

Update campaign status (for example pause or enable) after confirmation.

Requirements

Pro entitlement when the license requires it. Your TikTok ads app access must be approved. Approval may still be pending.

Example asks

  • Campaign insights for the last 7 days.

Guardrails

Status changes wait for your confirmation. If TikTok access or entitlement is missing, the agent reports that instead of inventing insights.
