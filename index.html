dgtl-connector

Install it. Read your own accounts.

A free local Grok plugin. You connect, pull, analyze, and recommend. A human publishes. The plugin reads back.

grok plugin install dgtlsunrise/dgtl-connector

The loop

Six steps. You publish.

  1. InstallPut the plugin on the machine you work on.
  2. AuthConnect Google accounts you already administer.
  3. PullRead GA4, Search Console, and Tag Manager on that machine.
  4. AnalyzeAsk the agent. Cite the property, site, or container on every number.
  5. RecommendThe agent drafts. Nothing sends until you say so.
  6. PublishA human publishes. The plugin reads the live result back.

Free path

Bytes stay off DGTL.

On the free path, tokens and report bytes never go through DGTL. The platform talks to the agent on the machine you installed.

Free is self-hosted. GA4, Search Console, and Tag Manager. No card. Server-side GTM is not in this version.

Pro

Ads and Meta, hosted.

Pro is $19/mo for the hosted Ads and Meta gateway only. One Polar customer. The same human may use more than one host. No employee seats. Unlimited ad accounts under that human's OAuth.

Google Ads is reporting only. Start at /connector#pro. Product page: /google-ads.
