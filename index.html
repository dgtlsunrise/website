DGTL Connector by DGTL Sunrise

A plugin that connects your agent to Google, Meta, Shopify, Klaviyo, and TikTok marketing accounts. These connections let your agent set up and manage accounts, pull reports, recommend changes, and push approved changes live after you review them. Built for Grok Bot first. It also works with other MCP hosts such as Cursor and Claude Desktop.

Install

You do not need a DGTL Sunrise account to get started. Pick your agent host.

Grok Bot

Install command 
grok plugin install dgtlsunrise/dgtl-connector

Cursor and Grok Build

Clone the public repo, build it, then load that folder as a local Agent Plugin (Cursor uses mcp.json; Grok Build uses .mcp.json).

Clone and build 
git clone https://github.com/dgtlsunrise/dgtl-connector.git
cd dgtl-connector
npm install
npm run build

Claude Desktop

Build the repo with the Cursor steps above, then add this stdio server in Claude Desktop MCP settings. Replace the paths with the absolute paths on your machine.

MCP server config 
{
  "mcpServers": {
    "dgtl-connector": {
      "command": "/path/to/dgtl-connector/bin/dgtl-connector-mcp",
      "env": {
        "PLUGIN_DATA": "/path/to/dgtl-connector-data"
      }
    }
  }
}

ChatGPT and other hosts that can run a local stdio MCP server use the same bin/dgtl-connector-mcp command after you build the repo. One-click marketplace install is Grok Bot first.

How to use it

  1. Install the plugin in your agent host.
  2. Connect the account that owns the property.
  3. Ask in chat.
  4. Review and approve before anything is published or changed on your accounts.

Never paste access tokens, refresh tokens, or license keys into chat.

Free and Pro

What is free

Install the plugin and connect the marketing accounts you already use. No DGTL Sunrise account is required.

  • Google Analytics 4, Search Console, and Tag Manager run on your machine (read and manage). Edits stay off until you enable writes on the install, and nothing goes live until you approve it. Report bytes stay on your machine and do not go through DGTL.
  • Klaviyo uses a private API key you hold on the install. Free. Not Pro. The key stays on your machine.
  • Shopify connects on the install. Catalog and inventory changes wait for your approval.
  • Google Business Profile can be read when that path is available. Edit is not in this version.

What is paid

Pro is $19 / month. It unlocks the hosted gateway for advertising platforms, plus Pro-gated Merchant Center on your machine:

  • Google Ads reporting, plus manage and create (campaigns, budgets, keywords, ads, and more).
  • Meta Ads insights, campaigns, ad sets, ads, audiences, catalogs, and Conversions API events.*
  • TikTok Ads advertisers, campaigns, insights, catalogs, and Events API tracking.*
  • Merchant Center accounts, products, and confirm-gated product-input writes. Plugin-direct Google on your machine (not the Ads/Meta/TikTok Worker hop).

Nothing is published or changed on your ad accounts until you review and approve it first.

*Meta Ads and TikTok Ads are included in Pro. We expect Meta and TikTok to finish approving our app access soon; until then some Meta or TikTok calls may wait on that approval.

Google Analytics 4

Overview

Ask your agent for GA4 properties, reports, and property settings the tools support.

Read

List accounts and properties. Open property details, data streams, and key events. Run reports for the date ranges and metrics you ask for.

Edit

Manage property settings the tools support (data streams, key events, custom definitions, and Measurement Protocol secrets where enabled). Live changes need your confirmation. Edits are off by default until you enable writes on the install.

Requirements

Free. Connect Google. Live edits need writes enabled on your install, plus confirmation.

Example asks

  • List my GA4 properties.
  • Sessions and conversions for this property over the last 28 days.
  • Which data streams are on this property?
  • Add this key event after I confirm.

Guardrails

If you have more than one property, the agent asks which one to use instead of guessing. It cites the property ID on numbers so you can see where a figure came from. It does not invent metrics the API did not return. Live edits wait for your confirmation.

Google Search Console

Overview

Ask your agent about verified sites, queries, URL indexing status, and sitemaps.

Read

List sites. Query search performance. Inspect a URL. List and open sitemaps.

Edit

Submit or delete sitemaps after you confirm. Edits are off by default until you enable writes on the install.

Requirements

Free. Connect Google. The site must already appear in Search Console for that account. Live edits need writes enabled on your install, plus confirmation.

Example asks

  • Which Search Console sites can I access?
  • Top queries for example.com over the last 28 days.
  • Inspect https://example.com/page for indexing issues.
  • Submit the sitemap for example.com after I confirm.

Guardrails

The agent asks which site to use when several are available. Search Console figures stay labeled as Search Console (they are not the same as GA4 sessions). Live edits wait for your confirmation.

Google Tag Manager

Overview

Ask your agent to inspect containers and to create or update tags, triggers, and variables. Publish after you approve. Edits are off by default until you enable writes on the install.

Read

List accounts, containers, workspaces, tags, triggers, and variables. Open a container. Show the live container version.

Edit

Create and update tags, triggers, and variables. Publish a container. Live changes need your confirmation. Writes are off by default until you enable them on the install.

Requirements

Free. Connect Google. Live edits and publishes need writes enabled on your install, plus confirmation.

Example asks

  • List my GTM containers.
  • What tags are in GTM-XXXX?
  • Propose a new tag, then publish only after I approve.

Guardrails

Draft or dry-run work stays separate from the live container until you approve publish. The agent will not publish without that confirmation.

Google Ads

Overview

With Pro, ask your agent for account reporting and confirm-gated changes (pause or enable, budgets, keywords, ads, and new campaigns where enabled).

Read

List accessible accounts. Account and campaign reporting. Search performance style queries. Merchant Center link status.

Edit

Pause or enable campaigns, ad groups, keywords, and ads. Update budgets. Add keywords and negatives. Create responsive search and display ads. Create Search, Display, Performance Max, Shopping, Video, Demand Gen, App, and Hotel campaigns. Upload assets. Set geo, language, demographics, schedules, and bidding. Create conversion actions and experiments. Link or unlink Merchant Center. Every live change needs confirmation.

Requirements

Pro ($19 / month). Connect Google Ads under your own login.

Example asks

  • List my Google Ads accounts.
  • Campaign performance for the last 14 days.
  • Pause this campaign after I confirm.
  • Create a paused Search campaign with these keywords.

Guardrails

Creates and status changes wait for your confirmation. Prefer paused drafts when you are testing. Without Pro, Ads tools do not invent results.

Meta Ads

Overview

With Pro, ask your agent for ad account insights and, when Meta access allows, create or update campaigns, ad sets, ads, and audiences.

Read

List ad accounts, campaigns, ad sets, and ads. Pull insights and creative details. List catalogs and catalog products.

Edit

Create and update campaigns, ad sets, and ads. Upload image or video. Create creatives. Update targeting. Create custom and lookalike audiences and attach them. Create a catalog and batch catalog products. Upload Conversions API events when that path is enabled on your install. Nothing goes live until you approve it.

Requirements

Pro. Meta must grant the needed app access for your account. Some write actions stay blocked until Meta finishes that review.

Example asks

  • List my Meta ad accounts.
  • Insights for this campaign over the last 7 days.
  • List catalogs on this ad account.
  • Create a paused campaign after I confirm.

Guardrails

The agent confirms before live changes. If Meta denies access, it reports that instead of inventing insights or edits.

Klaviyo

Overview

Ask your agent about your Klaviyo account, lists, segments, flows, campaigns, catalog, and reviews. When writes are enabled on your install, it can create a draft email campaign, send an existing draft after you confirm, and update profiles or catalog items.

Read

Open the account. List profiles (sparse fields only). Show lists, segments, flows, campaigns, and metrics. List catalog items, categories, and variants. List reviews.

Edit

Create a draft email campaign. Send an existing draft. That send needs its own confirmation. Upsert a profile. Create an event for backfill. Upsert catalog items (capped). Writes stay off until you enable them on the install, and nothing goes live until you approve it.

Requirements

Free. This is not a Pro feature. Connect Klaviyo with a private API key you hold on the install. That key stays on your machine. Never paste the key into chat.

Example asks

  • Which Klaviyo lists and segments can I access?
  • Show recent email campaigns and their status.
  • Create a draft email campaign after I confirm.
  • Send this existing draft after I confirm send.
  • Upsert this profile after I confirm.

Guardrails

The agent never asks you to paste the API key into chat. It asks which account or list to use when more than one is available. It does not invent profile fields. Creating a draft does not send it. A send needs its own explicit send confirmation.
